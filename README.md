# Sports Car Passport – MVP + Expert IA Offline

Application 100% locale pour propriétaires de voitures sportives.

## Fonctionnalités

- Garage multi-voitures
- Historique complet (entretiens, réparations, stages, pneus, factures…)
- Timeline visuelle
- Estimation de valeur indicative
- Export PDF pro
- **Expert IA 100% offline** spécialisé sportives (BMW M, AMG, Porsche, Audi RS…)

L’Expert IA utilise une base de connaissances intégrée. Aucune connexion internet, aucune API externe.

## Utilisation

1. Ouvre `index.html` dans ton navigateur
2. Ou lance un serveur local :
   ```bash
   python3 -m http.server 8000
   ```
   Puis va sur http://localhost:8000

## Expert IA

Onglet **Expert IA**. Pose des questions du type :
- Problèmes courants M2 / 911 / C63
- Rod bearings
- Coût entretien AMG
- Impact des mods sur la revente
- Assurance sportive France

Tout fonctionne même sans internet.
